Projet de fin d'études

NexusAI, agent conversationnel IA

Un agent IA cloud-native qui combine l'analyse de données de vente, la recherche augmentée (RAG) et la génération automatique de rapports PDF.

  • Python
  • Flask
  • Amazon Bedrock
  • Claude Haiku 4.5
  • pandas
  • Matplotlib
  • ReportLab
Entrée Question de l'utilisateur Dialogue avec l'agent
→
Agent cloud-native Flask + Amazon Bedrock Modèle Claude Haiku 4.5
→
Données de vente Analyse et graphiques pandas, Matplotlib
Connaissances RAG Génération augmentée par récupération
Livrable Rapport PDF ReportLab

Objectif

Concevoir un assistant qui répond en langage naturel à partir des données de vente d'une entreprise et qui produit lui-même des rapports prêts à partager.

Ce que j'ai fait

  • Conception et développement de l'agent de bout en bout, en Python avec Flask.
  • Intégration d'Amazon Bedrock et du modèle Claude Haiku 4.5.
  • Analyse des données de vente avec pandas et graphiques avec Matplotlib.
  • RAG, pour appuyer les réponses sur des sources plutôt que sur la seule mémoire du modèle.
  • Génération automatique de rapports PDF avec ReportLab.

Technologies et rôle

Python, Flask
Serveur de l'agent et logique de l'application.
Amazon Bedrock
Accès au modèle de langage depuis le cloud.
Claude Haiku 4.5
Modèle qui comprend les questions et rédige les réponses.
pandas
Analyse des données de vente.
Matplotlib
Graphiques illustrant l'analyse.
ReportLab
Génération des rapports PDF.

Compétences démontrées

  • IA générative
  • Architecture cloud-native
  • Analyse de données
  • Automatisation du reporting
  • Backend Python

Pourquoi ce projet compte

C'est mon projet de fin d'études. Il relie trois domaines que les entreprises cherchent à rapprocher : l'analyse de données, l'IA générative et le reporting automatisé. Il montre que je sais passer d'une analyse à un produit utilisable : un agent qui répond, calcule et livre un rapport.
